# Camera Calibration Console - Distribution Package

## Contents
- `setup.bat` - Environment setup (Python, venv, dependencies)
- `cleanup.bat` - Remove virtual environment and generated files
- `uv.exe` - Python package manager (used by setup.bat)
- `src/` - Source code
- `docs/` - Requirements and documentation

## Quick Start

1. Run `setup.bat` to configure environment
2. Run `run.bat` (generated by setup) to launch GUI
3. Run `cleanup.bat` when finished

## Requirements
- Windows 10/11
- PowerShell (for logging)
- CarMaker/IPGMovie installed (for calibration)

## Notes
- Logs are saved to `distribute/` directory
- First run may take a few minutes to install dependencies
- See `docs/` for detailed requirements
